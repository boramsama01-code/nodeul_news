## 작업 요약

기존의 "40개 주요 언론사 RSS + 네이버/다음 포털 검색" 이중 구조를 폐기하고,

## 수집 전략

두 가지 방법을 혼용한다:

**1. `rss_direct`** — 해당 언론사 RSS 피드에서 전체 기사를 수집한 뒤, 키워드("노들섬")로 필터링
**2. `google_news_rss`** — RSS가 없는 언론사는 구글뉴스 RSS로 대체 수집 (이미 "노들섬"으로 필터된 결과)

구글뉴스 RSS URL 패턴:
```
https://news.google.com/rss/search?q=노들섬+site:{domain}&hl=ko&gl=KR&ceid=KR:ko
```

## 구현 요구사항

### 1. 수집 로직

- `rss_direct` 방식: 해당 RSS URL fetch → XML 파싱 → title/description/link에 "노들섬" 포함 여부 필터링
- `google_news_rss` 방식: URL 그대로 fetch → XML 파싱 (이미 필터된 결과)
- 모든 수집은 **병렬 처리** (Promise.all 또는 동시 요청), 개별 타임아웃 10초
- 실패한 소스는 조용히 건너뜀 (전체 수집 중단 없음)

### 2. 중복 제거

- 동일 기사가 여러 소스에서 수집될 수 있음
- URL 기준 dedup 처리

### 3. 기존 소스 코드 교체

- 기존에 하드코딩된 40개 언론사 목록 완전 제거
- 네이버 검색 / 다음 검색 수집 로직 제거
- 위 JSON 데이터를 상수로 선언하고 수집 함수에서 참조하도록 수정

### 4. UI 표시

- 각 기사 카드에 언론사명(`name` 필드) 표시
- 수집 소스 방식(`method`)은 내부적으로만 사용, UI에는 노출 불필요

### 5. 수집 주기

- 기존 주기 유지 (변경하지 않음)

## 주의사항

- RSS URL이 실제로 동작하지 않는 경우를 대비해 각 소스별 try-catch 필수
- CORS 이슈가 있는 경우 백엔드 프록시를 통해 fetch
- 구글뉴스 RSS URL의 한글 인코딩: `노들섬`은 그대로 사용하거나 `%EB%85%B8%EB%93%A4%EC%84%AC`으로 인코딩
